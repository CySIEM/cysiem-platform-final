# MITRE ATT&CK Framework

## Description
MITRE ATT&CK is a globally recognized knowledge base of adversary tactics and techniques.

## Common Tactics
- Initial Access
- Execution
- Persistence
- Privilege Escalation
- Defense Evasion
- Credential Access
- Discovery
- Lateral Movement
- Collection
- Exfiltration
