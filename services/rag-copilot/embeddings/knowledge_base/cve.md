# Common Vulnerabilities and Exposures (CVE)

## Description
CVE is a publicly available catalog of known cybersecurity vulnerabilities. Each vulnerability is assigned a unique CVE identifier.

## Common Indicators
- Outdated software
- Missing security patches
- Known vulnerable services
- Exploitable applications

## Severity
Critical (depends on CVSS score)

## MITRE ATT&CK
Varies depending on the vulnerability.

## Prevention
- Regularly patch systems
- Perform vulnerability scanning
- Use vulnerability management tools
- Monitor vendor security advisories

## Detection
Identify vulnerable software using scanners such as Nessus, OpenVAS, or Microsoft Defender Vulnerability Management.

## Example
CVE-2021-44228 (Log4Shell) allowed attackers to execute remote code on vulnerable Java applications.
