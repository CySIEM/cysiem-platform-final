# Zero-Day Vulnerability

## Description
A Zero-Day vulnerability is a software flaw that is unknown to the software vendor or has no available security patch. Attackers exploit it before it is fixed.

## Common Indicators
- Unexpected application crashes
- Unknown malware behavior
- Antivirus bypass
- Suspicious network activity
- New exploit techniques

## Severity
Critical

## MITRE ATT&CK
Varies depending on the exploited vulnerability.

## Prevention
- Apply security updates immediately
- Use Endpoint Detection and Response (EDR)
- Enable application allowlisting
- Perform regular vulnerability scanning
- Monitor threat intelligence feeds

## Detection
Use behavioral analysis, EDR solutions, SIEM correlation, and anomaly detection to identify exploitation attempts.

## Example
Attackers exploit a newly discovered browser vulnerability before the vendor releases a security patch.
