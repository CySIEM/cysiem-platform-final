# cysiem-platform

Welcome to the **CySIEM Platform** repository.

CySIEM is an AI-powered Security Information and Event Management (SIEM) platform developed as part of our internship project. The goal of this project is to collect security logs, detect threats using AI, investigate incidents, and provide meaningful recommendations through an AI Security Copilot.

## Project Workflow

```
Data Collection
      ↓
Asset Intelligence
      ↓
AI Detection
      ↓
Correlation & Investigation
      ↓
RAG + AI Security Copilot
      ↓
Dashboard & Response
```
